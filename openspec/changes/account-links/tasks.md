# Tasks

This change builds on `web-library`; start it only once `web-library` is implemented. Cloud tests run with
`dotnet test src/cloud/Heavymatica.Cloud.Tests`. While a dev AppHost is running, add
`-p:OutDir=<repo>/src/cloud/Heavymatica.Cloud.Tests/bin/alt/`. AppHost tests need
`--Heavymatica:EphemeralStorage=true`. Tasks marked **(in-game check)** run in `runClient` with a
`HEAVYMATICA_DEV_SCREEN` script against the dev AppHost; tasks marked **(manual check)** run in a browser against the
dev AppHost with the local GitHub OAuth app.
